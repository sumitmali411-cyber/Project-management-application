Auth Flow (Keycloak)

Overview

DevSync uses Keycloak 24 as the OIDC identity provider with PKCE (S256) code flow. Angular frontend delegates all auth to keycloak-angular. Spring Boot validates tokens against the JWKS endpoint.

Sequence

Browser → Keycloak: Login redirect (PKCE)
Keycloak → Browser: auth_code
Browser → Keycloak: POST /token
Keycloak → Browser: access_token (15min)
Browser → Apiman: Bearer token
Apiman → Keycloak: JWKS validation
Apiman → Backend: Validated request
ℹ️ Token Refresh: Tokens expire in 15 minutes. keycloak-angular handles silent refresh via silent-check-sso.html.
